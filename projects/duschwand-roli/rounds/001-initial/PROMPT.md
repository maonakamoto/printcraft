# Grok v1 — Initial Generations (Mar 29-30)

## Approach
Each photo uploaded to Grok individually with basic prompts. No style reference image used.
Generated via manual Grok sessions and some via grok-generated/ folder downloads.

## Prompt (generic, per scene)
No consistent prompt was used across all 7. Each was generated ad-hoc asking Grok to create an illustration from the photo.

## Results
- 7 individual scenes generated
- Style varies significantly between images (different color palettes, line weights, rendering approaches)
- Usable individually but not as a unified set
- Scene 3 (red Amphicar) was later chosen as the **master style reference** for v2
